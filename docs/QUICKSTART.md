# WordLock Mobile - Quick Start

## You're Done! 🎉

Your WordLock game is now:
- ✅ A Progressive Web App (PWA) - installable on any device
- ✅ An Android app via Capacitor
- ✅ Ready to deploy

## Daily Workflow

### When you edit game code:
```bash
# 1. Copy your changes to www/
npm run copy

# 2. Sync to Android
npm run sync

# 3. Open in Android Studio (if testing on Android)
npm run open:android
```

**Or do all at once:**
```bash
npm run build:android
```

## Quick Commands

| Task | Command |
|------|---------|
| Test in browser | `npm start` then visit http://localhost:8000 |
| Copy files to www/ | `npm run copy` |
| Sync to Android | `npm run sync` |
| Open Android Studio | `npm run open:android` |
| Full build for Android | `npm run build:android` |

## Next Steps

### 1. Create App Icons (5-10 min)
```bash
# If you have a 512x512 logo.png:
npx @pwa/asset-generator logo.png ./icons --icon-only

# Then copy to www:
npm run copy
```

### 2. Test PWA (1 min)
1. Deploy to https://mimhoff.com/wordlock (or any HTTPS site)
2. Visit on phone
3. Menu → "Add to Home Screen"

### 3. Test Android App (5 min)
```bash
npm run build:android
# Click green play button in Android Studio
```

### 4. Deploy
- **Web**: Upload `index.html, game.js, styles.css, words.js, manifest.json, sw.js, icons/` to your server
- **Android**: Build APK in Android Studio → Build → Build APK

## File Structure

```
Root files (edit these):
├── index.html       ← Edit here
├── game.js          ← Edit here
├── styles.css       ← Edit here
└── words.js         ← Edit here

Generated (don't edit directly):
├── www/             ← Auto-copied from root
├── android/         ← Auto-generated by Capacitor
└── node_modules/    ← Dependencies
```

## Important Notes

⚠️ **Always edit files in the ROOT directory**, not in www/
⚠️ **Run `npm run copy` after making changes**
⚠️ **Don't commit node_modules/ or android/** (they're in .gitignore)
